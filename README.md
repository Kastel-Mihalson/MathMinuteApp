# Минутка

Мобильная игра на Flutter (Android + iOS): решай как можно больше примеров за 60 секунд.

## Как играть

- В центре экрана пример, внизу цифровая клавиатура.
- Верный ответ принимается сразу, как только набрано нужное число. Выражение вспыхивает **зелёным**, появляется следующий пример.
- Если набрано число той же длины, но неверное, выражение вспыхивает **красным**, ввод очищается.
- Таймер всегда 60 секунд.

## Что есть в приложении

- **Три сложности**: лёгкий, средний, сложный (за верный ответ 10 / 20 / 30 очков).
- **Профиль**: игры, верные ответы, точность, лучшая серия, лучшие результаты, последние игры.
- **Уровни и титулы**: очки превращаются в XP. Уровень 1: «Первооткрыватель», уровень 10: «Непоколебимый», всего 20 титулов (список в `lib/levels.dart`).
- **Светлая и тёмная темы**: кнопка в шапке главного экрана, по умолчанию как в системе.
- Данные хранятся на устройстве (`shared_preferences`).

## Сборка через GitHub

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки (ветка `main`).
2. Откройте вкладку **Actions**. Сборка запускается при каждом push, либо вручную: **Build apps → Run workflow**.
3. Когда сборка завершится, откройте запуск и скачайте файлы из блока **Artifacts**:
   - `minutka-android`: `app-release.apk` (ставится на телефон напрямую) и `app-release.aab` (для Google Play);
   - `minutka-ios-unsigned`: `minutka-unsigned.ipa` (без подписи).

Папки `android/` и `ios/` в репозитории не хранятся: workflow создаёт их командой `flutter create .`.

### Важно про iOS

Установить iOS-сборку на iPhone или выложить в App Store можно только с подписью Apple. Для этого нужен аккаунт Apple Developer (99 $/год), сертификат и provisioning profile, которые добавляются в GitHub Secrets. Без них workflow собирает проверочный unsigned-билд.

### Важно про Android

APK из workflow подписан отладочным ключом: годится для тестов. Для Google Play нужен свой release-ключ (keystore) и настройка подписи в `android/app/build.gradle`.

## Запуск на своём компьютере

```bash
flutter create . --platforms=android,ios --org com.example.minutka --project-name minutka
flutter pub get
flutter run
```

## Структура

```
lib/
  main.dart               запуск, темы
  theme.dart              цвета и темы
  app_state.dart          профиль, статистика, настройки
  levels.dart             уровни, XP, титулы
  widgets.dart            карточка уровня, плитка статистики
  game/problem.dart       сложности и генератор примеров
  screens/                главный экран, игра, итоги, профиль
.github/workflows/build.yml   сборка Android и iOS
```
